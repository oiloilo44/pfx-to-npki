# 홈택스 호환 NPKI 인증서 변환기 (PFX to NPKI Converter)

이 프로그램은 PFX(P12) 형식의 공인인증서(공동인증서)를 NPKI 표준 포맷(`signCert.der`, `signPri.key`)으로 변환해주는 도구입니다.

특히, **홈택스(Hometax) PC 버전**이나 은행 보안 프로그램에서 "신원확인정보 불일치" 또는 "비밀번호 오류"가 발생하는 문제를 해결하기 위해, PFX 파일 내부에 숨겨진 **VID(신원확인용 난수)**를 정밀하게 추출하여 완벽하게 호환되는 개인키 파일을 생성합니다.

## ✨ 주요 기능
- **VID 자동 추출**: OpenSSL 덤프 분석을 통해 암호화된 PFX 내부의 숨겨진 VID 값을 찾아냅니다. (홈택스 로그인 성공의 핵심)
- **완벽한 호환성**: 추출된 VID를 주입하고 SEED-CBC 알고리즘으로 암호화하여 NPKI 표준을 준수합니다.
- **자동 폴더 생성**: 인증서 표준에 맞춰 `NPKI\인증기관\User\DN값` 형태의 폴더 구조를 자동으로 생성합니다.
- **내장 OpenSSL 사용**: 별도의 OpenSSL 설치 없이, 프로젝트에 포함된 `openssl_bin`을 사용하여 작동합니다.
- **보안**: 비밀번호 입력 시 화면에 `*`로 표시됩니다.

## 📦 구성 요소
- `convert_pfx_to_npki.py`: 메인 변환 스크립트
- `openssl_bin/`: VID 추출을 위한 독립형 OpenSSL 실행 파일 모음
- `requirements.txt`: 파이썬 의존성 목록 (필요 시 생성)

## 🚀 사용/설치 방법

### 1. 의존성 설치
Python 3.x 환경이 필요하며, 아래 라이브러리를 설치해야 합니다.
```bash
pip install cryptography pypinksign
```

### 2. 실행
스크립트를 실행하면 대화형 프롬프트가 나타납니다.
```bash
python convert_pfx_to_npki.py
```

### 3. 변환 절차
1.  **PFX 파일 경로 입력**: 파일 경로를 직접 입력하거나, 같은 폴더에 PFX 파일이 있다면 엔터를 눌러 자동 선택할 수 있습니다.
2.  **비밀번호 입력**: 인증서 비밀번호를 입력합니다. (입력 시 `******`로 표시됨)
3.  **결과 확인**: 실행 위치에 `NPKI` 폴더가 생성됩니다.

### 4. 적용
생성된 `NPKI` 폴더를 통째로 복사하여 아래 경로(윈도우 기준)에 덮어씌우면 됩니다.
- `C:\Users\[사용자명]\AppData\LocalLow\NPKI`

## ⚠️ 주의사항
- **비밀번호**: 특수문자나 대소문자를 정확하게 입력해야 VID 추출이 가능합니다.
- **VID 추출 실패 시**: 비밀번호가 틀렸거나 PFX 파일에 VID 정보가 아예 없는 경우입니다. 이 경우 경고 메시지가 표시됩니다.
